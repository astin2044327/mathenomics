# Owner narration clips

Put **your** recorded phrase audio here. Learners never record.

## Naming

| Kind | File name |
| --- | --- |
| Lesson | `{courseId}-{lessonId}.webm` e.g. `g3-nines.webm` |
| Kids | `kids-{setId}-{Name}.webm` e.g. `kids-animals-Dog.webm` |

Also accepts `.mp3`, `.ogg`, `.m4a`.

## How to record

1. Open `tools/record-owner.html` in a browser (local file or via the same static server).
2. Enter the course/lesson (or kids set + name).
3. Record, download, move the file into this folder.
4. Reload Mathenomics and tap **Hear the phrase** / **Hear it**.

Until a clip exists for a lesson, the Hear button tells the learner that the voice clip is not added yet — it does **not** use device TTS for phrases.
