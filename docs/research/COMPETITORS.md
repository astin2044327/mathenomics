# Competitive landscape — Mathenomics (pending approval)

**Status:** research only — informs positioning; no code until canvas approved.  
**Source:** [competitor landscape research](0869fca0-3963-4ba7-9f19-b1d93a06383c).

## Verdict

Nothing open matches the full stack: **mnemonic-first + grade map + short play + cheatsheets + Kids + free accountless offline PWA**. Closest peers are song libraries (Numberock, OnlineMathLearning) without a unified playable app, or giants (Khan, IXL, Duolingo Math) that are not mnemonic-first.

## Peers (summary)

| Cluster | Examples | vs Mathenomics |
| --- | --- | --- |
| Song / rhyme | Numberock, Have Fun Teaching, OnlineMathLearning | Memory culture; not offline grade-trail game |
| Drill fluency | Times Tables Rock Stars, IXL | Speed/skills; paid/school; not phrase→exception |
| Full curriculum | Khan, CK-12 | Depth & brand; accounts/ecosystem; not mnemonic-first |
| Solvers | Photomath, Symbolab | Answer-first — competes for “stuck tonight” moment |
| Flashcards | Quizlet, Anki | Fragmented / DIY; weak Kids + grade trail |
| Gamified path | Duolingo Math | Closest UX threat if they add mnemonic-lite |

## Gaps Mathenomics owns (or could)

1. Phrase → Watch-out → 5-round game as atomic lesson  
2. Grade trail + per-grade cheatsheet, free installable  
3. Accountless `localStorage` progress  
4. True static offline PWA for weak Wi‑Fi / shared devices  
5. K–12 through advanced trig shelf + Kids soft on-ramp  

## Threats

YouTube song habit · solver culture · Duolingo/Khan mnemonic-lite · school-mandated TTRS/IXL · Anki power users for HS formulas  

## Positioning (candidates)

1. “The free offline mnemonic map for school math — one phrase per skill, then play it until it sticks.”  
2. “Not a solver, not a full curriculum: the cheatsheet you can install and quiz without an account.”  
3. “Songs and flashcards scattered the memory tricks; Mathenomics puts them on a grade trail with a game at every stop.”
