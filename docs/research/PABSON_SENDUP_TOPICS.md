# PABSON Send-up / Pre-board → Mnemonic Lesson Map

Skeleton mapping **expected send-up / pre-board topic groups** to Mathenomics mnemonic lesson ids for Compulsory Math (SEE Class 10) and adjacent NEB geo/trig practice.

**Disclaimer:** Group letters and mark schemes vary by year, district, and board set (classic A–D vs newer multi-group / 75-mark grids). This file maps **cognitive roles**, not a single fixed paper blueprint. Topic patterns only — no copyrighted question text.

**Related:** `docs/research/HS_THEOREMS_CATALOG.md`

## Role legend (A–D framing)

| Group role | Intent | Student job | Hub emphasis |
| --- | --- | --- | --- |
| **A — Formulas** | Knowledge / recall | Write the formula or one-line relation | Phrase + exception |
| **B — Short** | Understanding / quick apply | 1–2 step plug-in or angle chase | Phrase + 3 steps |
| **C — Long** | Application | Multi-part: compute / prove / construct | Full card + worked gen |
| **D — Creative / HA** | Higher ability | Compare, design, verify experimentally, “what if” | Stretch stem on same id |

*When a local paper uses Groups A–F by content (Sets, Finance, Mensuration, Algebra, Geometry, Stats/Prob), map each content block onto the same A–D roles below.*
