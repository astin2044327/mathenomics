## Notes on false positives

- **Low confidence:** correct value also appears as a **given** in the prompt (same number used as a side length, etc.).
- **Med:** match in table/col/note or duplicate givens in diagram.
- **High:** exact answer in SVG text or chain `<b>` with no `?` placeholder.
- Static lesson `pic:` on the learn screen is ignored; only `gen()` return values are tested.
